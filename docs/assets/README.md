# 📎 الملفات المساعدة (Assets)

هذا المجلد يحتوي على جميع **الملفات المساعدة** والموارد المرئية المستخدمة في الوثائق.

## هيكل المجلد

```
assets/
├── diagrams/                # المخططات والرسوم البيانية
│   ├── architecture/        # مخططات البنية
│   ├── workflows/           # تدفقات العمل
│   ├── database/            # مخططات قاعدة البيانات
│   ├── ui-ux/               # تصاميم الواجهة
│   └── network/             # مخططات الشبكة
│
├── screenshots/             # لقطات الشاشة
│   ├── ui-mockups/          # نماذج الواجهة
│   ├── error-screens/       # شاشات الأخطاء
│   ├── tutorials/           # صور تعليمية
│   └── examples/            # أمثلة عملية
│
├── templates/               # القوالب والنماذج
│   ├── document-templates/  # قوالب الوثائق
│   ├── email-templates/     # قوالب البريد الإلكتروني
│   ├── report-templates/    # قوالب التقارير
│   └── form-templates/      # قوالب النماذج
│
├── videos/                  # الفيديوهات التعليمية
│   ├── tutorials/           # دروس تدريبية
│   ├── demos/               # عروض توضيحية
│   └── walkthroughs/        # جولات تفصيلية
│
└── README.md               # هذا الملف
```

## أنواع الملفات المدعومة

### 🖼️ الصور والمخططات
- **تنسيقات مدعومة**: PNG, JPG, SVG, PDF
- **الدقة الموصى بها**: 1920x1080 للمخططات، 1280x720 للقطات الشاشة
- **التسمية**: استخدم أسماء وصفية بالإنجليزية مع شرطة سفلية

### 📊 المخططات
- **Architecture Diagrams**: مخططات C4، UML، ERD
- **Flow Charts**: تدفقات العمليات
- **Network Diagrams**: بنية الشبكة والخدمات
- **UI Wireframes**: رسومات الواجهة

### 📸 لقطات الشاشة
- **UI Examples**: أمثلة على الواجهات
- **Error Messages**: رسائل الأخطاء
- **Step-by-Step**: دليل خطوة بخطوة
- **Before/After**: مقارنات التحسينات

## معايير التسمية

### 📝 اصطلاحات التسمية
```
[نوع]-[وصف]-[تاريخ].[امتداد]
```

**أمثلة:**
- `architecture-system-overview-2025-12.png`
- `workflow-sales-process-2025-11.svg`
- `screenshot-login-form-2025-12.jpg`
- `diagram-database-schema-v2-2025-12.pdf`

### 🏷️ العلامات (Tags)
استخدم العلامات التالية في أسماء الملفات:
- `v1`, `v2`, etc. - لإصدارات مختلفة
- `draft` - للمسودات
- `final` - للنسخ النهائية
- `mobile`, `desktop` - للمنصات المختلفة

## إدارة الملفات

### 📁 تنظيم المجلدات
- **حجم الملفات**: لا يزيد عن 5MB للصور، 10MB للفيديوهات
- **التحديث**: احتفظ بالإصدارات القديمة في مجلد `archive/`
- **النسخ الاحتياطي**: احتفظ بنسخ في cloud storage

### 🔗 الربط في الوثائق
```markdown
<!-- صورة محلية -->
![وصف الصورة](../assets/diagrams/architecture-overview.png)

<!-- رابط خارجي -->
[![مخطط البنية]](https://example.com/diagram.png)
```

## أدوات التعديل

### 🎨 أدوات التصميم
- **Draw.io**: للمخططات والرسوم البيانية
- **Figma/Adobe XD**: لتصاميم الواجهة
- **Inkscape**: لتحرير SVG
- **GIMP/Photoshop**: لتحرير الصور

### 📹 أدوات الفيديو
- **OBS Studio**: تسجيل الشاشة
- **Camtasia**: تحرير الفيديوهات
- **Loom**: تسجيل فيديوهات سريعة
- **YouTube/Vimeo**: استضافة الفيديوهات

## تحسين الأداء

### ⚡ تحسين الصور
- **ضغط الصور**: استخدم TinyPNG أو ImageOptim
- **تنسيق WebP**: للصور على الويب
- **Lazy Loading**: للصور الكبيرة في الوثائق

### 📊 تحسين المخططات
- **SVG Preferred**: للمخططات القابلة للتكبير
- **PNG fallback**: للتوافق مع جميع المتصفحات
- **PDF export**: للمخططات المعقدة

## إرشادات الجودة

### ✅ معايير الجودة
- **الوضوح**: تأكد من وضوح النص والعناصر
- **الاتساق**: استخدم نفس الألوان والخطوط
- **الدقة**: تأكد من صحة المعلومات المعروضة
- **إمكانية الوصول**: دعم قارئات الشاشة والتنقل بالكيبورد

### 🔍 فحص الجودة
- [ ] هل الصورة واضحة ومقروءة؟
- [ ] هل الألوان مناسبة للمكفوفين؟
- [ ] هل حجم الملف مناسب؟
- [ ] هل التسمية وصفية ومفهومة؟
- [ ] هل الرابط يعمل بشكل صحيح؟

## الأرشفة والنسخ الاحتياطي

### 📦 نظام الأرشفة
- **المجلد archive/**: للملفات القديمة
- **النسخ الاحتياطي الأسبوعي**: في Git LFS
- **النسخ السحابية**: Google Drive، Dropbox
- **الإصدارات**: تتبع التغييرات باستخدام Git

### 🗂️ سياسة الاحتفاظ
- **الإصدارات الحديثة**: احتفظ بجميع الإصدارات لسنة
- **الإصدارات القديمة**: احتفظ بالإصدارات الرئيسية لـ3 سنوات
- **الملفات المؤقتة**: احذف بعد شهر من عدم الاستخدام
